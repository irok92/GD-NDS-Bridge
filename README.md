# GD-NDS-Bridge

This is a fork of NDS Ironmon Tracker for very specific usage, please see the [original project](https://github.com/Brian0255/NDS-Ironmon-Tracker) for more information.


Setting things up:
 Add the scripts from godot-scripts into your godot projects.
 You can remove the example ones if you want, but they are useful for testing.
